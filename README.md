# Tangled Friendships — Website Project

> Bracelet & accessories e-commerce website

---

## Phase I — Foundation & Layout

### Goal
Build the static HTML/CSS structure of the website: header, navigation, main sections, and footer. No backend, no JavaScript interactivity. Just a solid, styled, responsive base to build on.

---

**Sections to build:**

| Section | Description |
|---|---|
| Header | Logo + navigation bar (Home, About, Collections, Contacts, Account icon, Cart icon) |
| Hero | Full-width banner with brand tagline and a call-to-action button |
| About | Short brand description statement |
| Our Techniques | Description of how accessories are made |
| Collections | Grid of product category cards (bracelets, anklets, etc.) |
| Footer | Repeated nav links + social media links + copyright |

---

### Deliverables

- [ ] Semantic HTML skeleton for all sections
- [ ] CSS variables for the colour palette and typography
- [ ] Styled, responsive header with logo and nav
- [ ] Hero section with placeholder text
- [ ] About section with placeholder text
- [ ] Collections grid (placeholder cards)
- [ ] Styled footer
- [ ] Basic mobile responsiveness (single-column layout on small screens)
